# Sample data – synthetic / demo only

`sales_data.csv` is a **synthetic dataset created for demonstration purposes**.
It was generated by [`scripts/generate_sample_data.py`](../scripts/generate_sample_data.py)
with a fixed random seed. It does **not** describe any real company, customer, order or
person, and contains no personal information.

| Property | Value |
|---|---|
| Rows (order lines) | 1,480 |
| Orders | 1,000 (some orders contain 2–3 products) |
| Date range | 2 Jan 2024 – 31 Dec 2025 |
| Products | 29 across 6 categories |
| Regions | Northeast, Southeast, Midwest, Southwest, West |

Built-in patterns so the analysis has something to find: a holiday peak in
November/December, gradual growth over the two years, occasional promotional
discounts and uneven product and regional popularity.

To recreate the file exactly:

```bash
python scripts/generate_sample_data.py
```
